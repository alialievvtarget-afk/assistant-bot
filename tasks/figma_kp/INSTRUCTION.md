# Как сделать редактируемую КП-презентацию в Figma через плагин

Это инструкция для Claude: как превратить контент презентации (текст, слайды)
в редактируемый Figma-файл — без платных сервисов, без VPN-хаков, без
конвертеров HTML→Figma (они не работают криво).

Единственный рабочий путь: **написать маленький Figma-плагин на JS**, который
сам рисует фигуры/текст на Figma-канвасе через Figma Plugin API. Пользователь
устанавливает его вручную (2 клика) и запускает — плагин сам всё строит.

## Шаг 1. Понять контент

Собери у пользователя:
- Тема/клиент КП
- Сколько слайдов и что на каждом (заголовок, буллеты, цифры, картинки — если есть)
- Цветовая палитра (или используй дефолтную ниже)
- Логотип/название компании

Не выдумывай данные — если чего-то не хватает, спроси.

## Шаг 2. Взять шаблон

В этом комплекте два файла:
- `template/manifest.json` — не трогать, только можно поменять `name` и `id`
- `template/code.js` — каркас с готовыми функциями. Допиши в конец файла
  секцию, которая создаёт конкретные слайды под контент пользователя
  (см. пример структуры слайда в конце code.js).

Готовые хелперы уже в файле:
- `mkFrame(parent, x, y, w, h, fill, radius, name)` — создать фрейм/слайд
- `mkRect(parent, x, y, w, h, fill, radius)` — прямоугольник/карточка
- `mkText(parent, txt, x, y, w, size, style, color, align, lh, ls)` — текст (async!)
- `solid(color)` — заливка сплошным цветом
- `gradFill(color1, color2)` — градиентная заливка

Размер слайда: 1920×1080. Между слайдами делай отступ (gap) 80–120px по X,
раскладывая их в ряд слева направо.

## Шаг 3. КРИТИЧЕСКИЕ правила Figma Plugin API (иначе не запустится)

1. **Никогда не используй spread-оператор** `{...obj}` — Figma sandbox (QuickJS)
   его не поддерживает, будет синтаксическая ошибка при запуске плагина.
   Пиши поля объекта явно: `{r: c.r, g: c.g, b: c.b, a: 1}`.
2. **Шрифты грузить асинхронно перед использованием**:
   ```js
   await figma.loadFontAsync({family: "Montserrat", style: "Regular"});
   await figma.loadFontAsync({family: "Montserrat", style: "Bold"});
   // и так для каждого style, который используешь (Black, ExtraBold, SemiBold, Medium...)
   ```
   Если шрифта Montserrat нет в системе Figma — используй `Inter` (всегда доступен)
   или спроси пользователя, какой шрифт есть у него в Figma.
3. Всё выполняется в `code.js`, `manifest.json` просто прописывает точку входа.
   Не пытайся подключать внешние npm-пакеты — это чистый sandboxed JS.
4. В конце скрипта вызови `figma.closePlugin()` (после завершения отрисовки)
   и `figma.viewport.scrollAndZoomIntoView(...)`, чтобы пользователь сразу
   увидел результат.

## Шаг 4. Установка плагина пользователем (сделай это пользователю простой инструкцией)

1. Открыть Figma (desktop app)
2. Menu → Plugins → Development → **Import plugin from manifest...**
3. Выбрать файл `manifest.json` из папки плагина
4. Menu → Plugins → Development → выбрать плагин по имени → запустить
5. Слайды появятся на канвасе, дальше редактируются руками как обычные объекты

## Шаг 5 (опционально). PDF-версия для отправки клиенту

Если нужен PDF (не редактируемый, для быстрой отправки):
1. Сделать HTML-версию тех же слайдов (тот же контент/стиль)
2. Скриптом на Python + Playwright сфотографировать каждый слайд:
   - `element.screenshot(path=..., type="png")` — именно элемент, не всю страницу
   - `color_scheme="light"`, `device_scale_factor=2` для чёткости
   - Дождаться `networkidle` + ~2 сек, чтобы шрифты успели загрузиться
   - Убрать из HTML любые служебные подписи (нумерацию и т.п.) перед скриншотом
3. Собрать PNG-скриншоты в один PDF через PIL (`Image.save(..., save_all=True)`)

## Частые ошибки (не повторять)

- ❌ html.to.design — плагин заблокирован без VPN
- ❌ Другие HTML→Figma конвертеры — результат кривой, требует полной переделки руками
- ❌ Просто вставить готовые PNG-картинки в Figma — это не редактируемый макет
- ❌ Base64-шрифты внутри HTML — раздувают файл, ломают парсинг в Playwright
- ❌ Spread-оператор в коде плагина — Figma sandbox падает с ошибкой

## Дефолтная палитра (если пользователь не дал свою)

```js
const C = {
  bg:        {r:0.922, g:0.922, b:0.922}, // #EBEBEB фон
  blue:      {r:0.290, g:0.565, b:0.851}, // #4A90D9 акцент
  blueDark:  {r:0.169, g:0.369, b:0.655},
  white:     {r:1,     g:1,     b:1    },
  dark:      {r:0.102, g:0.102, b:0.102}, // текст
  gray:      {r:0.4,   g:0.4,   b:0.4  },
  lightGray: {r:0.6,   g:0.6,   b:0.6  },
};
```
